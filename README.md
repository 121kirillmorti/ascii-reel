# ASCII REEL

Ч/б интерактивное портфолио: облако символов образует 3D-голову, а при вращении точки сами собираются в ASCII-логотипы проектов. Дальнейшее вращение переключает кадр; после проектов — соцсети и немного о жизни.

## Как это работает

- Вращение: мышь/тач, колесо, стрелки, кнопки ↑/↓ или точки слева.
- Один оборот = один кадр. В середине оборота точки сходятся в картинку, дальше — снова разлетаются в 3D-модель и готовятся к следующему.
- Сайт сам медленно крутится, пока ты ничего не трогаешь.
- Никаких библиотек и сборщиков: чистые HTML/CSS/JS.

## Что где редактировать

- `data.js` — имя, проекты, описания, теги, соцсети. Главный файл для правок.
- `avatar-data.js` — ASCII-версия GitHub-аватара, сгенерированная из `assets/avatar.png`.
- `tools/generate_avatar.py` — пересоздаёт `avatar-data.js` из свежей аватарки (нужен Pillow).
- `app.js` — 3D-облако точек и сборка кадров.
- `styles.css` — ч/б оформление.

## Локальный запуск

```bash
python -m http.server 4173
# открыть http://127.0.0.1:4173
```
