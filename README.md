# куб

Сайт, который можно крутить. Собрал его для себя, чтобы были все проекты в одном месте и чтобы выглядело не как обычное резюме.

Куб простой: на шести гранях логотипы — мой аватар, StickCommander, m5wheel-ets2, justvibrait, Tetris You и GitHub в конце. Тянешь мышкой — он вертится во все стороны, под нужным углом становится видно следующий логотип.

## Как крутить

- тянуть мышкой или пальцем — вращение в любую сторону;
- колесо — тоже поворот;
- стрелки, кнопки ↑↓ или точки слева — перейти к нужной грани.

## Где что лежит

- `data.js` — тексты, проекты и ссылки. Тут всё можно переписать под себя.
- `logo-data.js` — логотипы в виде символов, собраны из настоящих ассетов репозиториев.
- `tools/generate_logos.py` — если нужно пересобрать логотипы (Pillow + resvg-py).
- `avatar-data.js` и `tools/generate_avatar.py` — аватар из GitHub в символах.
- `app.js` — сам куб и вращение.
- `styles.css` — чёрный фон, белые рёбра и зелёные логотипы.

## Запуск

```bash
python -m http.server 4173
```

Потом открыть `http://127.0.0.1:4173`. На GitHub Pages лежит в корне ветки `main`.
