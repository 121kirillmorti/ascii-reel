# ASCII CUBE

Бело-зелёный интерактивный 3D-куб в ASCII. На шести гранях — настоящие логотипы проектов, взятые из их репозиториев. Куб вращается мышью/тачем/колесом и сам медленно крутится, пока его не трогают; при повороте на переднюю грань выходит следующий логотип.

## Грани

1. Аватар / профиль
2. StickCommander
3. m5wheel-ets2
4. justvibrait
5. Tetris You
6. GitHub / финал

## Управление

- перетаскивание — вращение куба;
- колесо — поворот;
- стрелки / кнопки ↑↓ / точки слева — переход к нужной грани.

## Что где редактировать

- `data.js` — описания проектов, теги, соцсети, тексты.
- `logo-data.js` — ASCII-версии логотипов (сгенерированы).
- `tools/generate_logos.py` — пересобирает логотипы из репозиториев (нужны `Pillow` и `resvg-py`).
- `avatar-data.js` / `tools/generate_avatar.py` — ASCII-аватар.
- `app.js` — геометрия куба, вращение, рендер.
- `styles.css` — бело-зелёное оформление на чистом чёрном фоне.
